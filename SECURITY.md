# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability or Secret Bypass

Security is the core mission of SecretGuard. If you discover a security vulnerability, an interception bypass, or an unhandled false positive edge case:

1. **Do not disclose the issue publicly** in open GitHub issues or forums.
2. Please report findings via GitHub's [Private Vulnerability Reporting](https://github.com/hemanathk636/secretguard/security/advisories/new) or directly contact the maintainers.
3. Include:
   - Command pattern or secret format that triggered or bypassed detection.
   - Operating system and shell environment (Zsh, Bash, Fish, NuShell, PowerShell).
   - Any proposed fix or mitigation steps.

We will acknowledge receipt within 24 hours and coordinate a patch release promptly.
