Pillar 1: Ambient Shield • Set & Forget
1. Shell Pre-Exec Line Interceptor (`secretguard hook`)
Attaches a sub-millisecond (15.68 µs) hook into Zsh, Bash, or PowerShell. When you press Enter on any command containing an OpenAI token, AWS secret, or Postgres URI, SecretGuard redacts it in memory before it ever reaches ~/.zsh_history.

Pillar 1: Zero-Knowledge TLS Swapper
3. In-Flight TLS Secret Swapper (`secretguard tun`)

Frequently Asked Questions

Simple answers to common questions about shell integration, privacy, and safety.

Will SecretGuard slow down my terminal?
No. Humans cannot perceive lag under 50 milliseconds. SecretGuard runs in 0.016 milliseconds (15.68 microseconds)—over 3,000 times faster than human perception. It feels completely instantaneous.
Does SecretGuard send my data anywhere?
Never. SecretGuard has zero telemetry, zero analytics, and zero network calls. It is a 100% offline compiled binary running solely on your local CPU.
How does the Zero-Knowledge TLS Swapper work?
You use harmless placeholder tokens like mock_openai_token in your scripts and curl commands. SecretGuard's local loopback TLS tunnel swaps the mock token with your real secret in-flight inside the network packet. Your real token never touches bash history, logs, or agent scratchpads.
Can 'time-machine' corrupt my Git history?
No. SecretGuard automatically generates an atomic backup branch in .git/refs/original/ before any commit tree manipulation. If you ever need to restore your pre-scrubbed state, you can revert with one git command.
How does it protect Claude Code and Cursor?
AI coding assistants save approved shell commands in .claude/settings.local.json. Running secretguard protect-agent audits these files, replaces exposed keys, and ensures sensitive agent directories are excluded in .gitignore.
Is SecretGuard free and open-source?
Yes! SecretGuard is 100% free, open-source software dual-licensed under MIT and Apache-2.0. You can inspect the complete Rust source code on GitHub.
