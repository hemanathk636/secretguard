🛡️ Automatic Shell Protection (`hook`)
Adds a lightning-fast sub-millisecond hook into your shell (Zsh, Bash, or PowerShell). Every time you hit Enter, SecretGuard scans the command line: if you typed an OpenAI, AWS, or database secret, it automatically scrubs the token before saving to your persistent history file.

Frequently Asked Questions ❓

Simple answers to common questions about shell integration, privacy, and safety.

⚡ Will SecretGuard slow down my terminal?
No. Humans cannot perceive lag under 50 milliseconds. SecretGuard runs in 0.016 milliseconds (15.68 microseconds)—over 3,000 times faster than human perception. It feels completely instantaneous.
🔒 Does SecretGuard send my data anywhere?
Never. SecretGuard has zero telemetry, zero analytics, and zero network calls. It is a 100% offline compiled binary running solely on your local CPU.
💾 Can 'clean-history' corrupt my shell history file?
No. SecretGuard uses atomic file replacement: it writes the cleaned history to a temporary file, verifies it, creates a timestamped copy (e.g. .zsh_history.backup.<time>), and renames atomically. Your original file is always backed up.
🤖 How does it protect Claude Code and Cursor?
AI coding assistants often save approved shell commands in .claude/settings.local.json. Running secretguard protect-agent audits these files and automatically makes sure they are excluded in your .gitignore.
