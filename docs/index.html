Engineered for Technical Paranoia

Designed for senior engineers, infrastructure leads, and autonomous AI coding agents.

Autonomous AI Coding Agent Shield
Directly mitigates disclosures regarding terminal coding assistants (Claude Code, Cursor, Aider). Command secretguard protect-agent audits local agent working trees and prevents unmasked secrets in .claude/settings.local.json and MCP configs from being committed to Git.
$ secretguard protect-agent
> Checking .claude/settings.local.json ... [1 EXPOSED KEY]
> Git safety: Appending .claude/ to .gitignore ... [PROTECTED]

Atomic History Sanitizer
Audit years of terminal history in seconds with secretguard audit. Atomically rewrite dirty history files with automatic rollback backups (.zsh_history.bak).
Real-Time Stdout Masking (`wrap`)
Running dev servers or containers on video calls? Prefix your commands with secretguard wrap <cmd> to dynamically mask connection strings, tokens, and authorization headers from ever displaying on standard output during live Zoom, Teams, or demo sessions.
$ secretguard wrap npm run dev
[dotenv] Loaded DATABASE_URL=postgres://user:[REDACTED]@localhost/prod
