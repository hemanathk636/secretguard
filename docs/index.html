🛡️ Core Protection • Set & Forget
1. Automatic Terminal Shield (`secretguard hook`)
Attaches a 0.016ms line hook to your shell (Zsh, Bash, PowerShell). The instant you press Enter, SecretGuard scans the command: if it has an OpenAI key, AWS token, or database password, it redacts it before saving to ~/.zsh_history.
$ eval "$(secretguard hook zsh)" ✅ SecretGuard live interceptor attached to Zsh! $ curl -H "Authorization: Bearer sk-proj-98a7sdf987asdf" https://api.openai.com ⚠️ [SecretGuard] Intercepted exposed OpenAI API Key! 🔒 Line saved to ~/.zsh_history as: curl -H "Authorization: Bearer sk-p[REDACTED]" https://api.openai.com
eval "$(secretguard hook zsh)"
🔍 History Scan • 0.05s
2. Scan History Leaks (`audit`)
Scans your entire shell history file (thousands of past commands) in milliseconds and shows you every secret already exposed on your laptop.
$ secretguard audit 🔍 Scanning ~/.zsh_history (4,820 commands)... ⚠️ [Line 142] AWS Access Key (AKIA...) ⚠️ [Line 891] Database Password URI (postgres://...) ──────────────────────────────────────── Found: 2 exposed secrets in your history
secretguard audit
🧹 Safe Atomic Clean
3. Clean History Safely (`clean-history`)
Safely scrubs leaked credentials from your history file. Automatically creates a timestamped backup (.zsh_history.bak) before touching anything.
$ secretguard clean-history Found 2 exposed secrets. ⚠️ Safely sanitize 2 secrets in history? (y/N): y 📦 Safe backup created: ~/.zsh_history.backup.174 ✨ Successfully sanitized 2 commands!
secretguard clean-history
🤖 AI Agent Protection
4. Shield AI Coding Agents (`protect-agent`)
Protects Claude Code, Cursor, and MCP caches in .claude/settings.local.json so local AI credentials never get pushed to public GitHub repos.
$ secretguard protect-agent 🤖 Inspecting AI agent configs in '.'... ⚠️ .claude/settings.local.json contains unmasked key! 🔒 Added '.claude/' to .gitignore automatically. ✅ Workspace shielded from accidental Git pushes!
secretguard protect-agent
👁️ Screen Share Cloak
5. Cloak Screen Shares (`wrap`)
Prefix any command with secretguard wrap to mask tokens, passwords, and database URLs from ever displaying on your screen during Zoom or demo calls.
$ secretguard wrap npm run dev [dotenv] Loaded environment variables: DATABASE_URL="postgres://user:[REDACTED]@db:5432/main" OPENAI_API_KEY="sk-proj-[REDACTED]" 🔒 Safe for screen sharing: tokens masked on stdout.
secretguard wrap npm run dev

Frequently Asked Questions ❓

Simple answers to common questions about shell integration, privacy, and safety.

⚡ Will SecretGuard slow down my terminal?
No. Humans cannot perceive lag under 50 milliseconds. SecretGuard runs in 0.016 milliseconds (15.68 microseconds)—over 3,000 times faster than human perception. It feels completely instantaneous.
🔒 Does SecretGuard send my data anywhere?
Never. SecretGuard has zero telemetry, zero analytics, and zero network calls. It is a 100% offline compiled binary running solely on your local CPU.
💾 Can 'clean-history' corrupt my shell history file?
No. SecretGuard uses atomic file replacement: it writes the cleaned history to a temporary file, verifies it, creates a timestamped copy (e.g. .zsh_history.backup.<time>), and renames atomically. Your original file is always backed up.
🤖 How does it protect Claude Code and Cursor?
AI coding assistants often save approved shell commands in .claude/settings.local.json. Running secretguard protect-agent audits these files and automatically makes sure they are excluded in your .gitignore.
